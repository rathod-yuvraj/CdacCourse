SQL IN Operator: Complete Concept Guide
✅ What Is the IN Operator?
The IN operator is used in SQL to filter records where a column's value matches any value in a specified list. It’s a shorthand for multiple OR conditions.

sql
-- Instead of this:
SELECT * FROM Employees WHERE Department = 'HR' OR Department = 'Finance' OR Department = 'IT';

-- Use this:
SELECT * FROM Employees WHERE Department IN ('HR', 'Finance', 'IT');
📌 When to Use IN
When you want to match multiple values in a column.

When the list of values is known and fixed.

When using a subquery to filter based on another table’s results.

🎯 Why Use IN
Cleaner syntax than multiple OR conditions.

Improves readability and maintainability.

Can be used with subqueries for dynamic filtering.

Often more efficient than multiple ORs in some databases.

🛠️ How to Use IN
sql
SELECT column1, column2
FROM table_name
WHERE column_name IN (value1, value2, value3);
You can also use it with subqueries:

sql
SELECT Name
FROM Students
WHERE ClassID IN (SELECT ClassID FROM Classes WHERE Grade = '10');
🧩 Sample Problem Statement: Mastering the IN Operator
Scenario:
You are a data analyst for a university. The university stores student data in a table called Students.

Table: Students
StudentID	Name	Department	Year	GPA
1	Aditi Sharma	CS	2	8.5
2	Ravi Kumar	EE	3	7.8
3	Neha Singh	ME	2	9.1
4	Aman Verma	CS	1	8.0
5	Priya Desai	CE	3	7.5
Task 1: Basic Use of IN
Question: Write an SQL query to retrieve all students from the CS, EE, and ME departments.

Expected Output:

StudentID	Name	Department	Year	GPA
1	Aditi Sharma	CS	2	8.5
2	Ravi Kumar	EE	3	7.8
3	Neha Singh	ME	2	9.1
4	Aman Verma	CS	1	8.0
SQL Query:

sql
SELECT *
FROM Students
WHERE Department IN ('CS', 'EE', 'ME');
Task 2: Using IN with Subquery
Question: Find students who are in departments that have at least one student with a GPA above 9.

SQL Query:

sql
SELECT *
FROM Students
WHERE Department IN (
    SELECT DISTINCT Department
    FROM Students
    WHERE GPA > 9
);

SQL BETWEEN Operator: Complete Concept Guide
✅ What Is the BETWEEN Operator?
The BETWEEN operator in SQL is used to filter records within a range. It works with numeric, date, and text values (depending on the database).

sql
SELECT * FROM Orders
WHERE TotalAmount BETWEEN 1000 AND 3000;
This returns all orders with TotalAmount greater than or equal to 1000 and less than or equal to 3000.

📌 When to Use BETWEEN
To filter data within a numeric range (e.g., prices, scores, quantities).

To select records within a date range (e.g., orders between two dates).

To match alphabetical ranges (e.g., names between 'A' and 'M') — though this is less common.

🎯 Why Use BETWEEN
Simplifies range filtering compared to using >= and <=.

Improves readability of queries.

Works with dates, numbers, and text.

Can be used with NOT BETWEEN to exclude ranges.

🛠️ How to Use BETWEEN
sql
SELECT column1, column2
FROM table_name
WHERE column_name BETWEEN value1 AND value2;
value1 is the lower bound.

value2 is the upper bound.

Both bounds are inclusive.

SQL LIKE Operator: Complete Concept Guide
✅ What Is the LIKE Operator?
The LIKE operator is used in SQL to search for a specific pattern in a column. It’s commonly used with text/string data and supports wildcards to match flexible patterns.

sql
SELECT * FROM Customers
WHERE Name LIKE 'A%';
This query returns all customers whose names start with 'A'.

🛠️ Syntax of LIKE
sql
SELECT column1, column2
FROM table_name
WHERE column_name LIKE pattern;
🔡 Wildcards Used with LIKE
Wildcard	Meaning	Example
%	Matches zero or more characters	'A%' → starts with A
_	Matches exactly one character	'A_' → A followed by one character
[ ]	Matches any single character within brackets (some DBs)	'A[bc]%' → starts with Ab or Ac
[^ ]	Matches any character NOT in brackets (some DBs)	'A[^x]%' → starts with A but not Ax
📌 When to Use LIKE
Searching for partial matches in text fields.

Filtering records by prefix, suffix, or contains.

Validating simple patterns (e.g., email domains, phone formats).

When exact match (=) is too restrictive.

🎯 Why Use LIKE
Enables flexible pattern matching.

Useful for search features in applications.

Works well with wildcards for fuzzy filtering.

Can be combined with NOT LIKE to exclude patterns.
