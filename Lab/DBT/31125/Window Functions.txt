What Are SQL Window Functions?
A window function performs a calculation across a set of rows related to the current row, called a window. Unlike aggregate functions (like SUM() or AVG()), window functions do not collapse rows—they return a result for each row.

Basic Syntax:

sql
function_name (expression) OVER (
  PARTITION BY column1
  ORDER BY column2
  ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW
)
🔧 Common SQL Window Functions
Function	Purpose
ROW_NUMBER()	Assigns a unique sequential number to rows
RANK()	Ranks rows with gaps for ties
DENSE_RANK()	Ranks rows without gaps for ties
NTILE(n)	Divides rows into n buckets
LAG()	Accesses data from a previous row
LEAD()	Accesses data from a following row
SUM()	Running total over a window
AVG()	Moving average over a window
Sources: Dynamic Duniya, Analytics Engineering

📌 When to Use Window Functions
To rank or number rows within partitions

To calculate running totals or moving averages

To compare values between rows (e.g., current vs. previous)

To retain row-level detail while performing aggregations

ROW_NUMBER()
The ROW_NUMBER() function in SQL assigns a unique sequential number to rows within a result set, 
making it ideal for tasks like pagination, ranking, and filtering duplicates. 
Below is a breakdown of its concepts with examples and solutions.

🧠 What Is ROW_NUMBER()?
It's a window function that assigns a sequential integer to rows.

Syntax:

sql
ROW_NUMBER() OVER (PARTITION BY column1 ORDER BY column2)
PARTITION BY: Optional. Divides rows into groups.

ORDER BY: Mandatory. Defines the order of numbering.

📘 Key Concepts with Examples
1. Basic Usage
Assign row numbers to all rows in a table.

sql
SELECT 
  employee_id, 
  employee_name, 
  ROW_NUMBER() OVER (ORDER BY employee_name) AS row_num
FROM employees;
✅ Solution: Each employee gets a unique number based on alphabetical order.

2. Using PARTITION BY
Assign row numbers within each department.

sql
SELECT 
  department_id, 
  employee_name, 
  ROW_NUMBER() OVER (PARTITION BY department_id ORDER BY employee_name) AS dept_rank
FROM employees;
✅ Solution: Resets numbering for each department.

3. Pagination
Retrieve rows 11–20 from a result set.

sql
WITH NumberedRows AS (
  SELECT 
    employee_id, 
    ROW_NUMBER() OVER (ORDER BY employee_id) AS row_num
  FROM employees
)
SELECT * FROM NumberedRows
WHERE row_num BETWEEN 11 AND 20;
✅ Solution: Efficient pagination without OFFSET.

4. Removing Duplicates
Keep only the first occurrence of each duplicate.

sql
WITH Ranked AS (
  SELECT *, 
    ROW_NUMBER() OVER (PARTITION BY email ORDER BY user_id) AS rn
  FROM users
)
DELETE FROM Ranked WHERE rn > 1;
✅ Solution: Deletes duplicate emails, keeping the earliest user.

5. Top-N per Group
Get top 3 students per class by marks.

sql
WITH RankedStudents AS (
  SELECT *, 
    ROW_NUMBER() OVER (PARTITION BY class_id ORDER BY marks DESC) AS rank
  FROM students
)
SELECT * FROM RankedStudents
WHERE rank <= 3;
✅ Solution: Filters top performers in each class.

🧪 Practice Problem
Problem: You have a table sales(region, salesperson, amount). Write a query to find the top 2 salespeople per region based on sales amount.

Solution:

sql
WITH RankedSales AS (
  SELECT *, 
    ROW_NUMBER() OVER (PARTITION BY region ORDER BY amount DESC) AS rank
  FROM sales
)
SELECT * FROM RankedSales
WHERE rank <= 2

The SQL ROW_NUMBER() function is a powerful window function that assigns a unique sequential number to each row within a partition of a result set. It’s especially useful for ranking, pagination, and filtering top-N results.

🧠 Concept of ROW_NUMBER()
Syntax:

sql
ROW_NUMBER() OVER (
  PARTITION BY column1
  ORDER BY column2
)
PARTITION BY: Optional. Divides the result set into groups.

ORDER BY: Required. Determines the order of numbering within each partition.

🔧 Common Use Cases
1. Pagination
Assign row numbers to help paginate results:

sql
SELECT *
FROM (
  SELECT ROW_NUMBER() OVER (ORDER BY created_at) AS row_num, *
  FROM orders
) AS numbered_orders
WHERE row_num BETWEEN 11 AND 20;
2. Top-N per Group
Get the top 3 earners per department:

sql
SELECT *
FROM (
  SELECT employee_id, department, salary,
         ROW_NUMBER() OVER (PARTITION BY department ORDER BY salary DESC) AS rank
  FROM employees
) AS ranked_employees
WHERE rank <= 3;
3. Deduplication
Keep only the first occurrence of each duplicate:

sql
SELECT *
FROM (
  SELECT *, ROW_NUMBER() OVER (PARTITION BY email ORDER BY created_at) AS rn
  FROM users
) AS deduped
WHERE rn = 1;

The ROW_NUMBER() function in SQL is a window function that assigns a unique sequential number to each row within a result set. It’s especially useful when you want to rank, paginate, or filter rows based on specific criteria—without collapsing them into groups.

🧠 How ROW_NUMBER() Works
Syntax:

sql
ROW_NUMBER() OVER (
  PARTITION BY column1
  ORDER BY column2
)
PARTITION BY: (Optional) Divides the result set into partitions. Row numbering resets for each partition.

ORDER BY: (Required) Determines the order in which row numbers are assigned.

📊 Example
Imagine a table called employees:

employee_id	department	salary
1	Sales	50000
2	Sales	60000
3	HR	55000
4	HR	52000
You want to rank employees by salary within each department:

sql
SELECT employee_id, department, salary,
       ROW_NUMBER() OVER (PARTITION BY department ORDER BY salary DESC) AS rank
FROM employees;
Result:

employee_id	department	salary	rank
2	Sales	60000	1
1	Sales	50000	2
3	HR	55000	1
4	HR	52000	2
🔧 Common Use Cases
Top-N filtering: Get the top 3 products per category.

Pagination: Show rows 11–20 in a result set.

Deduplication: Keep only the first occurrence of each duplicate.

Ranking: Assign ranks based on scores or metrics.

What Is LAG() in SQL?
The LAG() function is a window function that retrieves the value of a column from a row that precedes the current row by a specified offset. It’s commonly used to:

Compare current and previous values

Detect changes or trends

Calculate differences between rows

Syntax:

sql
LAG(expression [, offset, default]) OVER (
  PARTITION BY column1
  ORDER BY column2
)
expression: The column to retrieve from the previous row.

offset: How many rows back to look (default is 1).

default: Value to return if the offset row doesn’t exist.

📊 Example Use Cases
1. Compare Monthly Sales
sql
SELECT month, sales,
       LAG(sales) OVER (ORDER BY month) AS previous_month_sales,
       sales - LAG(sales) OVER (ORDER BY month) AS sales_difference
FROM sales_data;
Shows how sales changed month-over-month.

2. Track Employee Salary Changes
sql
SELECT employee_id, salary,
       LAG(salary) OVER (PARTITION BY employee_id ORDER BY change_date) AS previous_salary
FROM salary_history;
Compares each employee’s current salary with their previous one.

3. Detect Status Changes
sql
SELECT user_id, status,
       LAG(status) OVER (PARTITION BY user_id ORDER BY timestamp) AS previous_status
FROM user_activity;
Identifies when a user’s status changes (e.g., from "active" to "inactive").
